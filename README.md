# OmniDesk – Backend

OmniDesk is a backend REST API application developed using **Java and Spring Boot** to manage customer information efficiently. It provides API endpoints for performing CRUD (Create, Read, Update, Delete) operations on customer records and uses **MySQL** for persistent data storage.

The application follows a layered architecture with Controller, Service, Repository, and Entity components to maintain clean code organization and separation of concerns.

**Technologies Used:** Java, Spring Boot, Spring Data JPA, Hibernate, MySQL, Maven, REST APIs, Postman.

**Key Features:**
- Create and store customer records.
- Retrieve customer information through REST APIs.
- Perform customer management operations.
- Persist data in a MySQL database.
- Test and validate APIs using Postman.
- Integrate with a React frontend application.
